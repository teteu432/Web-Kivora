# Auréa Clínica Estética — Demo Web Kivora

Projeto demonstrativo em HTML, CSS e JavaScript puro.

## Como executar

1. Abra a pasta no VS Code.
2. Você pode abrir `index.html` diretamente no navegador.
3. Para melhor experiência, use a extensão Live Server.

## Agendamento

O fluxo salva agendamentos em `localStorage`, usando a chave `aurea_appointments`.

## Painel administrativo

Acesse `admin.html`.

Credenciais demonstrativas:

- E-mail: `admin@aurea.com`
- Senha: `admin123`

Essa autenticação é apenas visual e não deve ser utilizada em produção.

## Reset da demonstração

No painel, clique em **Redefinir demonstração** para restaurar os dados iniciais.

## Publicar na Vercel

Como o projeto é estático, basta importar a pasta/repositório na Vercel e manter as configurações padrão. Não é necessário comando de build.

## Personalização

Os principais dados que devem ser substituídos para um cliente real são:

- Nome e slogan
- WhatsApp
- Instagram
- Endereço
- Horários
- Textos
- Tratamentos
- Profissionais
- Imagens da pasta `images/`

Projeto demonstrativo desenvolvido para o portfólio da Web Kivora.
