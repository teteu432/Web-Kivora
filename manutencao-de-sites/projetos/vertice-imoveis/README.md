# Vértice Imóveis — Demo Web Kivora

Projeto demonstrativo de site imobiliário desenvolvido em HTML, CSS e JavaScript puro.

## Páginas
- `index.html` — Home
- `imoveis.html` — Catálogo com filtros e ordenação
- `imovel.html?id=1` — Página dinâmica do imóvel
- `contato.html` — Contato/captação de lead

## Funcionalidades
- 12 imóveis fictícios em `js/data.js`
- Busca da home
- Filtros por finalidade, tipo, cidade, bairro, preço, quartos e vagas
- Ordenação
- Favoritos com `localStorage`
- Galeria e lightbox
- WhatsApp dinâmico conforme o imóvel
- Formulário "Tenho interesse" salvo localmente
- Imóveis semelhantes
- Responsividade

## Como usar no projeto Web Kivora
Coloque a pasta inteira dentro de:

`LangePages/projetos/vertice-imoveis/`

E use no card da página principal:

`/LangePages/projetos/vertice-imoveis/index.html`

## Observação
As imagens são carregadas de URLs públicas do Unsplash para facilitar a demonstração. Para um projeto comercial real, baixe imagens licenciadas e hospede-as localmente.
